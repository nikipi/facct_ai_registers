# facct_ai_registers

This repository contains the data and code used to generate the figures presented in the paper *Understanding the Role of Algorithm Registers in AI Governance Through
Comparative Analysis of China and the UK*.

## Repository structure

- `data/`  
  Contains the datasets used in the analysis.

- `code/`  
  Contains the notebooks used to analyze the data and generate the figures and graphs reported in the paper.

## Reproducibility

All figures in the paper can be reproduced by running the scripts in the `code/` directory on the datasets provided in the `data/` directory.
